# 四种积分排名算法对比

## 一、算法概述

本文对比四种常用选手积分排名算法：Elo、SDR、Glicko-2 和融合算法。

---

## 二、算法原理

### 2.1 Elo 算法

基于期望值的评分系统。核心公式：
- E_A = 1 / (1 + 10^((R_B-R_A)/400))
- R'_A = R_A + K * (S_A - E_A)

特点：简单直观，只考虑胜负结果。

### 2.2 SDR 算法

在Elo基础上引入比分差异因素：
- R'_A = R_A + K * (W_A + M * D - 0.5)

特点：对比分敏感，大胜获得更多积分。

### 2.3 Glicko-2 算法

贝叶斯推断的动态技能评估系统。每个选手有三个参数：
- R：评分
- RD：评分偏差（不确定性）
- σ：评分波动性

特点：评分稳定，长期跟踪能力强。

### 2.4 融合算法

结合Glicko-2的稳定性和SDR的比分敏感性。

## 三、特性对比

| 特性 | Elo | SDR | Glicko-2 | 融合算法 |
|------|-----|-----|----------|----------|
| 比分敏感 | 否 | 是 | 否 | 是 |
| 评分不确定性 | 否 | 否 | 是 | 是 |
| RD衰减 | 否 | 否 | 是 | 是 |
| 复杂度 | 低 | 低 | 中 | 中 |

---

## 四、优缺点对比

| 算法 | 优点 | 缺点 |
|------|------|------|
| Elo | 简单快速 | 不考虑比分 |
| SDR | 比分敏感 | 波动大 |
| Glicko-2 | 稳定可靠 | 计算复杂 |
| 融合算法 | 兼顾各方 | 复杂度较高 |
