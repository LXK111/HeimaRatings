# 阶段 37：轮空与奇数晋级提示

## 修改历史

| 版本 | 日期 | 作者 | 说明 |
|------|------|------|------|
| v0.1 | 2026-07-01 | Codex | 创建阶段 37 执行记录，新增轮空可见提示和奇数晋级保护 |

## 范围

- 在管理端签表视图中显式提示首轮轮空选手。
- 当前轮完成后如果胜者数量为奇数，展示需要轮空落位的提示。
- 禁用奇数胜者直接生成下一轮，避免未配对胜者被静默丢失。
- 在 Mock 和 Supabase Repository 的晋级路径增加同样的奇数胜者保护。

## 非目标

- 不新增数据库表。
- 不新增 `bracket_slots`。
- 不创建虚拟轮空比赛。
- 不自动推进轮空选手。
- 不修改公开页。

## 实现记录

- 更新 `components/matches/bracket-board.tsx`：
  - 接收项目参赛名单。
  - 识别已报名但未出现在首轮对阵中的选手，并展示首轮轮空提示。
  - 当前最新轮胜者数量为奇数时展示轮空落位提示。
- 更新 `components/matches/match-workbench.tsx`：
  - 在比赛录入页按当前项目加载参赛名单。
  - 将参赛名单传入签表视图。
  - 当前轮完成后胜者数量为奇数时禁用“生成下一轮”。
- 更新 `lib/server/repositories/mock.ts`：
  - 晋级时拒绝奇数胜者直接生成下一轮。
- 更新 `lib/server/repositories/supabase.ts`：
  - 晋级时拒绝奇数胜者直接生成下一轮。

## 当前限制

- 本阶段只让轮空可见并阻止错误晋级，不提供完整自动轮空落位。
- 奇数晋级的自动推进需要后续引入明确的 slot/bye 模型。
- 手动比赛录入场景如果没有参赛名单，只能基于已有 matches 显示签表。
