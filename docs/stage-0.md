# 阶段 0：项目初始化与工程规范

## 范围

- 建立 `Next.js + TypeScript + Tailwind CSS` 基础工程。
- 创建 `app`、`components`、`lib`、`docs`、`public` 模块目录。
- 首页使用 Mock 数据展示 HEMA Ratings MVP 的多武器积分池方向。

## 暂不包含

- 暂不接入 Supabase。
- 暂不实现 Route Handlers API。
- 暂不调用 Python 排名算法。
- 暂不实现完整选手、赛事、比赛录入页面。

## 后续衔接

- 阶段 1：落地数据库与基础数据模型。
- 阶段 2：扩展 Web UI 页面和组件。
- 阶段 3：接入 API 与 Ranking Engine。
